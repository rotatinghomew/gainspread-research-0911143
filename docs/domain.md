# 重复商户面板中的降价收益分布资料约定

经营日数不是权重，样本权重不是采购量。分层和簇号描述抽样设计，同一商户在不同月份保持身份。采购表只反映已观测经营月份，缺行须结合经营资格与回收状态解释。参考价的品规与采购品规对应，节省额可以为负。月份采用公历整月，退出与未回收分开保存，不允许默认为相同状态。

## 数据表

### `merchants`

退出月为不再经营的首月，入场月为首个经营月，不完整观察不同于退出。

| `id` | `text` |
| `group` | `text` |

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。

## 面板节省额分析口径

`GET /panel` 在商户层定义节省额：对每条采购行，以同品规可比参考价减去实付价，乘以采购公斤数；商户跨月只形成一条期间记录。负节省额保留，不静默删除。采购量、支出与节省额分别报告：支出下降可能只是因为少买，不能据此称为受益。

- 参考价模式：`matched` 使用当月参考价，包含参考价随时间的变化；`frozen` 把参考价冻结在基期月份均值；`pooled` 使用分析期全部月份均值。三者回答不同问题，均不是反事实，也不得互相替代。
- 权重：`weight_design` 使用 `panel_design.weight` 的期间均值，是抽样权重而非采购量；`weight_equal` 每商户计一次，用于对照。没有设计权重记录的商户按 1 进入加权并在 `weight_attachment` 中计数。
- 月份：未观察月份没有虚构零采购行。已观察但没有采购行的月份同样不生成零节省额记录，而在 `observed_without_purchase` 与诊断中单列。
- 入场与退出按 `merchants.entry_month` 与 `exit_month` 判定；某期缺行但登记月不能解释的，标为不完整观察，不当成入场或退出。退出与未回收分开。
- 两期比较同时给出共同商户、入场、退出与总体结果。均值可加分解为构成项、组内项、交互项，以及整组只在一期出现时的组出现/消失项，各项相加等于加权总均值差；组间差距是横截面概念，单列而不计入。分布重叠与分位数变化另行报告。两期都没有期间记录的已登记商户单列：既包括两期之间入场又退出者，也包括有可经营月份但没有采购行者，均不等同于退出。
- 底部覆盖分别按节省额、支出与采购量排序，三者含义不同。`by_savings` 是结果最差，不等于规模最小。
- 分布指标在数学不适用时返回 `applicable: false` 与原因。含负节省额时基尼系数与 p90/p10 不计算；不发布单一“普惠程度”指数。
- 敏感性包括不同参考价模式、极端大户（按采购量删除，报告总量与加权均值变化）、缺失月份（完整月份商户对全部可观察商户，跨度含两期之间所有自然月）、共同商户截尾/缩尾均值，以及经营日数折算。经营日数折算只调整规模，不改变单价与节省额方向。
- 共同商户逐户明细同时给出采购量、支出、节省额及其变化；采购量下降可以直接带来支出下降，因此不能把支出变化当作节省额变化。
